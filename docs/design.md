# 架构

独立 Swift Package，最低 macOS 13，只有 Apple 系统框架依赖。

## 模块

- `AuthCore`：倒计时、窗口策略、确认票据、焦点恢复限制、普通权限语义、历史与规则模型。
- `MacAuthAssistant`：原生 UI、菜单栏与登录项、钥匙串、可信系统窗口扫描、受控聚焦、单次提交、诊断与本机历史存储。
- `Tests`：核心行为与原生适配回归。手动测试程序只位于 `Tests/Fixtures`。

## 管理员处理

扫描器核对系统提供方标识、系统路径及实际 Apple 签名，识别安全密码框与真实确认按钮。聚焦仅针对唯一合格的系统窗口，每窗口最多两次请求；点击位置先核对几何、顶层窗口和 PID。下一轮独立确认焦点，才开始倒计时。

提交前复核同一窗口、焦点、时间票据及黑名单。密码按 Unicode 标量边界分段，仅通过定向 PID 键盘事件发送，随后重验并点击真实 AXButton。来源标记防止本工具生成的事件误触人工输入取消。窗口仍存在时停止重试。

## 普通权限

独立开关与扫描器复用倒计时和 AX 工具，只扫描可信系统 UserNotificationCenter。按正文语义及精确允许按钮匹配，优先单次允许，其次使用期间允许。管理员窗口存在时让出处理顺序。确认前复核同一窗口、正文和按钮；单次点击后检查窗口是否关闭，不使用回车、默认按钮或任意窗口兜底。

## 历史与过滤

两条流程共享 ActivityHistory，通过临时窗口 token 去重。ActivityRequest 只持久化应用、摘要和规范化静态正文的 SHA-256 指纹。规则支持精确指纹或类型、类别、关键词组合：同条 AND，多条 OR。管理员聚焦前及两类提交前重新检查。

最近 1000 条记录保留结果和原因；成功只代表自动确认后窗口关闭。原记录已终结时不覆盖其原因，规则停用后仍可处理的请求开始新记录。进程重启后未完成项标为忽略。私有本机 JSON 原子保存；读取失败保留原文件并停止自动操作，保存失败提示；清空历史保留规则。

历史列表逐行提供一键加入与移出入口，不经过规则编辑表单。直接屏蔽使用现有精确请求规则，自动填写名称与类型，复用同一请求已有的规则；保存成功后才显示“已加入”，失败回滚内存规则状态。移出仅停用此精确规则，不操作高级规则或改写原历史结果。没有任务指纹的旧记录不能自动创建范围更大的规则。

CountdownGate 区分黑名单的可恢复暂停与明确取消/已提交的永久抑制。管理员及普通权限协调器在选择窗口和原有取消判断前，暂停刚被屏蔽的活动倒计时，清除待执行目标和显示。移出后同一窗口恢复完整倒计时，已终结的忽略历史保留并开始新处理记录；不会复活人工取消或已提交窗口。

普通权限协调器允许测试注入窗口扫描、信任状态、确认动作及诊断存储；正式初始化仍使用原生扫描器、AX 信任检查和原有按钮检查。集成回归使用隔离数据验证完整状态变化，不访问真实系统权限 UI，也不写用户诊断文件。

## 持久化与启动

凭据在钥匙串；设置在 UserDefaults；诊断与历史在用户 Application Support。无数据库或长期 root 服务；更新仅访问公开 GitHub 发行源，不上传运行数据。SMAppService.mainApp 管理登录项，用户从系统设置关闭后不强行重新注册。正常启动只建立菜单栏和检测，设置/历史/更新窗口由用户打开。

签名身份决定系统授权及钥匙串访问连续性。构建必须显式选择稳定证书或无证书审查模式，无静默临时签名回退；证书私钥和本机身份配置不属于源码。

## 版本与更新

Version.json 为版本、递增构建号和最低系统要求的唯一来源。AppVersion/AppRelease 处理 SemVer、固定发行源、附件校验元数据与架构/通道选择。UpdateController 管理异步检查、跳过、下载状态和本机偏好；UpdateService 只访问公开发行 API 与附件。UpdatePackage 复核压缩包、Info.plist 和指定签名要求；UpdateInstaller 启动无特权独立安装脚本，在原进程退出后同目录整体替换并保留旧包。原自动认证流程只增加正在处理时的安装阻止条件，不改变其认证策略。参考 Launchpad 的发行目录与下载校验方法，未依赖或复制其私有业务模块。
